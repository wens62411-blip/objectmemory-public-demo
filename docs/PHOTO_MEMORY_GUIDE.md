# 照片识别、最后位置与场景位置图

本轮使用当前项目，分支 `codex/photo-memory-core`。这是已接入真实本地模型的实验能力，不是已经验证可以稳定区分所有家庭实物的成熟产品。

## 最短使用流程

1. 启动现有 REAL 服务，在“物品管理”选择已有物品或“添加物品”。进入“管理照片 / 测试识别”，上传 JPEG/PNG，或从已经运行的摄像头抓拍。单张即可开始，建议逐步补充 6–12 张正面、背面、侧面与实际摆放视角。手机可以在同一局域网的受访问码保护页面上传照片；HEIC 等不支持格式需先转换。
2. 每张图点击“确认这是我的物品”，调整目标框，尽量去掉手和背景，然后“建立 / 更新识别档案”。“图片已保存”“档案已就绪”“摄像头已加载当前版本”是三个不同状态，不能跳过目标确认。
3. 到“实时画面”启动本机摄像头。流畅预览旁默认显示同帧识别面板，不再需要先进入诊断才能看物品框；两者的实际频率不同，框不会贴到另一张更新画面上。再回物品管理“测试识别”，使用不同于参考照片的真实视角，查看手机类别是否检出、是否接受为当前物品以及拒绝原因。分数是余弦相似度，不是准确率。
4. 在“家庭场景”点击“识别当前场景”。家具模型建议只是框，需手动调整到实际可放置区域并逐个确认。可以没有建议而手动画区域。保存后是图像坐标示意，不是房间重建或厘米级地图。
5. 普通首页/搜索按最新可靠观察回答，点击地图上的物品查看其观察截图与时间。无标签识别不要求手部成功、完整拿放或视频编码成功才能记住“最后看到”。

## 一次集中完成的物理试验

下列试验需要用户自己的物品、不同于注册图的视角和实际动作，当前没有以生成图代做。完成前不宣称实物准确率通过。

| 场景 | 应看到的结果 |
| --- | --- |
| 启动时手机已在桌上 | 连续可靠识别后有最后看到和一张同源截图；没有虚构刚刚放下 |
| 手未识别到，手机移动到另一已确认区域 | 新的可靠观察可更新；动作不足时只说位置变化，不确认放下 |
| 手拿着手机保持静止 | 手邻近时不能仅凭静止计时确认放下 |
| 手机移动中被遮挡 | 保留最后真实观察时间；符合全部依据才显示明确的推测，不能猜成桌下或抽屉中 |
| 另一部相似手机入镜 | 不确定时拒绝身份；若错误接受，应补充负例/视角并停止把该匹配视为可靠，不能宣传可稳定区分 |
| 相机转动/分辨率改变/重启 | 旧场景需复核，不把全画面位移当成物品移动；没有新来源帧时不更新位置 |

建议先将物品在镜头中拍清楚，避免远处只剩几十像素。现场测试可看具体拒绝原因；不要用降低阈值的方式掩盖身份错误。

## 模型与证据边界

- 路线 B：现有 OpenCV Zoo NanoDet-m-plus-1.5x 416（`object_detection_nanodet_2022nov.onnx`）找 COCO 类别候选；DINOv2-small ONNX 在候选裁剪上与用户确认的多视角裁剪做身份匹配；使用类别、绝对阈值、第二候选差距和连续帧门。
- DINO 转换仓库 `onnx-community/dinov2-small`，固定 revision `8b1f705a3a7f6f062f6bdd21986c1583d3ef105d`，FP32 权重 88,532,934 字节，SHA-256 `f22797eabf810a75e41de68d378541ebea372122b25c4ce3ef25ff618250c20a`。ONNX Runtime 1.22.1，384 维归一化特征，当前在 CPU 上运行。
- 2026-09-06 起使用 `bicubic-fit224-blackpad-l2-v2`：完整物品等比缩放并补边，避免中心裁切截断手机；旧 v1 向量不兼容，需用已确认参考框重建。新版差异与有限公开样本验证见 [预处理说明](APPEARANCE_PREPROCESSING_V2.md)。
- DINOv2 原项目标注 Apache-2.0；具体转换仓库没有独立明确许可声明，不能据可下载直接承诺闭源商业授权。版本、预处理与许可记录见 `services/vision/detectors/appearance-model.json`。
- 手部复用本地 MediaPipe Hand Landmarker Tasks VIDEO；单调时间戳，同帧 21 点，配置最多两手。已新增独立显示/分析、多帧姿势、持续手身份与手物交互；左右手分类分数不是手部存在可信度，邻近不是抓握。完整条件和本轮验证见 [手部动作说明](HAND_ACTION_GUIDE.md)。
- 所有家庭图像在本机处理。模型准备过程访问公开下载源，运行中不下载，不将家庭图片上传远程模型。
- NanoDet 的类别与远景检出能力有限，尤其钥匙、钱包和相似外观可能没有有效候选。当前没有 YOLOE、分割、独立抓握分类器或深度模型。

## 状态与存储

`last_observed`、`last_confirmed_placement`、`location_hypotheses` 分开。预测不推进观察时间；新的可见证据清空旧推测。旧确认放置保留为历史，不覆盖更新的观察。

当前观察最多一张主截图，不保存连续录像；同位置观察节流刷新图像，截图保留自己的时间/帧号，不冒充每次观察帧。位置显著变化、源会话变化或达到 30 秒刷新间隔时才替换。新图写失败不伪造新截图，也不丢掉可靠观察。MINIMAL 的最近两次变化、固定证据、当前证据保护继续有效，注册原图不受普通事件清理影响。

场景每台相机保留一张来源绑定的快照。人工确认不等于精确标定；机位稳定性不足时仅供人工参考，不用于确认放置。重启后需重新取景复核。没有尺度、不输出厘米或米，不共用未知的多平面变换。
