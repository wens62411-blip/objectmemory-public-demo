- 原有 NanoDet 经常把用户手机背面当遥控器，无法进入手机身份匹配；原照片整体 DINO 特征在独立现场帧也未过身份门。这是真实漏检，不是用户没保存照片。
- 增加现有本地 DINO 模型的注册照片局部特征定位。确认的参考 ROI、原图/显示图哈希、档案版本、前景与背景区分、空间聚类及身份歧义均检查。生产输入是完整现场帧与固定窗口，**不使用人工真值框指导检测**，不把遥控器改名手机。
- 同一物品的局部框与通用模型框在双向唯一匹配时合并；一个大框包含两件物品时不贪心合并。修复“同一部手机被重复候选误判为身份冲突、无法更新位置”的实际文件流水线故障。
- 局部身份证明只供当前帧、当前检测对象一次使用；复制元数据、跨帧重放、旧档案和不同物品歧义不能更新位置。
- 连续身份观察通过后维护当前状态；首次可靠观察可保存一张“最后看到”截图，**不是确认放下**。同位置持续观察仅更新必要字段，不每帧保存图片或录像。
- 旧整体相似度与新局部相似度不是同一个指标，不能把新分数当成提升后的概率或声称覆盖所有视角。黑色矩形、手机类别也不等于用户注册的那一台。

### 手拿起 → 放下并稳定五秒

- 同一手轨迹与物品共同移动，随后必须实际观察到分离；物品持续稳定五秒才允许确认放置。分离被观察并确认后，手可以离开摄像头视野。
- 五秒内重新拿起、移动、遮挡、身份丢失、手模型不健康或来源断流，取消计时/恢复跟踪，不能用旧帧累加时间。
- 手物状态机与证据门使用同一配置时间，不再额外串联另一段五秒等待。缺少完整动作仍只记最后看到/被遮挡，不猜放置位置。
- 过程视频采用有界内存环形缓冲，保护起点至放稳的同源过程；64 MB 上限。关键帧、短片的来源会话、帧范围、时间和 SHA-256 对应，缓冲被截断则拒绝确认历史事件。
- 一次完整移动对应一个事件。异步写媒体失败不杀死视觉线程；新观察图失败保留旧图及旧图自己的时间/哈希。沿用 MINIMAL 最近两次未固定事件、当前证据与 pinned 保护。

### 连续画面、语音及场景

- 共享一次取流/推理，订阅者不重复打开摄像头；预览独立调度，客户端单帧背压、两张固定图像缓冲，下一张解码完成后图和框一起切换。断流撤图撤框，不持续重播旧帧。
- 光流是真实像素跟踪而非画框动画；模型周期重新校验身份。光流显示不是新的识别或位置证据。局部特征四窗口合批，保留相同特征与判定，减少重复模型调用。
- 找物页支持用户点击后的单轮语音查询与朗读。优先可用的本地中文识别；联网语音须另行同意，无自动监听。回答通过真实搜索接口，保留最后时间、未确认/遮挡等状态及“摄像头画面左/右”的方位边界。
- 场景页无已有场景时可依据新鲜相机帧自动建立相对草稿并保存；重入不重复创建，不能覆盖已有人工场景。真实 Three.js 网格可以旋转/缩放；无家具检出不补假家具。
- 二维框不能证明支撑接触或真实深度；未标定/未确认接触时仅显示区域，不编造精确 XYZ。人物是独立匿名人体/姿态轨迹，脚点不可靠时不放到地面。

### ESP32-CAM / XIAO ESP32S3 Sense 自动刷入与联动

- 已接入“设备中心 → 绑定这块板”。首次管理员确认固定板型、目标端口及覆盖原固件后，读取芯片/MAC，再自动刷固定产物、配网、核对串口 OMREADY 与后台注册、绑定摄像头。设备页明确区分 AI Thinker ESP32-CAM 与 Seeed XIAO ESP32S3 Sense，不复用另一板型的通过状态。
- 默认未绑定不开监听。廉价 CH340 可使用 USB 序列号或 VID/PID + 固定 USB 位置；多串口、未知位置、换芯片 MAC 不自动擦写。ROM 身份核验与写入使用同一个连接。
- 仅支持两个固定配置：原版 ESP32 的 AI Thinker 4 MB Flash/min_spiffs，以及 XIAO ESP32S3 Sense 的 8 MB Flash/独立分区与针脚。产物目录隔离；固件清单、四个写入文件哈希/长度、镜像 chip_id/Flash 容量及分区标志均核验。清单变化必须重新授权。
- SQLite 在写入前记录执行占位；同板同版本只有一次自动刷写尝试。失败/重启不循环擦写；已有成功收据的重插只恢复连接。Wi-Fi 信息仅在后台内存，初次配网中途重启后需要重新输入。
- 编译成功、ROM 绑定、串口注册、实际视频就绪是独立状态。缺少串口证据返回 esp32_unverified；没有实际视频不宣称摄像头可用。设备令牌无管理员刷写权限。
- 后置独立复查修复了串口重开风险：每次打开先验证绑定 USB 桥，在同一连接上用新 nonce 核对固件返回的 eFuse MAC，确认后才发 Wi-Fi 配置；重新连接必须重新核验。旧 nonce、换板或超时不发送密码。这是连接连续性校验，不是抵抗恶意硬件仿冒的密码学认证。
- 有新的管理员 Wi-Fi 授权时，即使数据库已存在旧设备也重新配网并轮换一次性授权；没有新配置的同版本重插只恢复连接，不静默忽略用户的新配置，也不反复刷写。
- ROM 无法独立辨别摄像头针脚/底板电路，仍需用户确认型号及真实硬件验收。不支持其他任意 ESP32-S3/C3，不包含 OTA。XIAO 原生 USB 复位后 COM 号改变时，仅跟随同一 USB 桥并重新挑战身份，不向另一个串口发送 Wi-Fi。
- 新固件要求用途分离的视频读取凭据，保护 `/capture`、`/device` 和两个 `/stream` 入口；后端仅在 adapter 内存和 HTTP 头使用派生值，不进入公开配置/URL。匿名旧固件明确拒绝。响应白名单、已知秘密值脱敏、JSON/图片容量、JPEG 解码像素与单帧读取总时限均有限制。
- 这是局域网 HTTP 访问控制，不是 TLS 或加密 NVS；无法承诺防同网段嗅探。后台撤销传播依赖心跳，非离线瞬时撤销。仅 AP 实际接口可提交备用配网，普通 STA 局域网请求不能改配置。
