## 四、链路、模式与存储

来源 → 帧/会话 → ArUco 身份 → 跟踪 → 区域 → 状态机 → 证据门 → 原子媒体 → SQLite → 搜索 → 页面。ArUco 是标签辅助识别，不是无标签 AI。

REAL 使用 `data/database/objectmemory.sqlite` 和 `data/real-media`，DEMO 使用 `objectmemory-demo.sqlite` 和 `demo-media`，TEST 使用临时库/媒体。模式固定到进程；正常启动不 seed、不开视频或虚拟设备。无合格证据显示“暂时没有真实摄像头产生的位置记录。”

MINIMAL 每物品最近两条未固定确认事件；当前状态、pinned、参考图、当前证据和人工纠正唯一证据受保护。普通事件一张主截图和一短片；P0 独立前后证据是明确例外：两图一片，最近两事件共六文件。超额历史只留小型受控回执，不留额外视频。文件丢失或篡改不能冒充正常策略删除。

清理采用 pending_delete 两阶段、路径限制、模式租约、事务保护复检和失败恢复。离线清理默认 dry-run。新增测试实际通过 EventService 写四次移动，离线清成两事件/六媒体；注入文件删除失败时，回执未完成不能提前计分，重试完成后恢复。
