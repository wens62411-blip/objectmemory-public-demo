## 独立发现并修复

- **P1 · DashboardPage**：没有 movement events 不代表没有 last_observed。首页现在只陈述历史移动事件为空，不否认最后观察。
- **P1 · ItemsPage**：类型折叠后易将手机保存为默认“日常物品”，通用手机候选被严格类别门拒绝。类型恢复外显并解释用途，不放松身份过滤。已有默认值仍保留，注册时仍需选择正确类别。
- **P1 · registration.py**：真实浏览器测试暴露既有长路径问题。最终裁剪路径合法，但临时文件重复拼接目标名和 UUID，超过 Windows 路径限制而返回 422。改为同目录独立短 UUID 临时名，仍原子重命名；不宣称支持任意长度的最终路径。
- **P2 · SearchPage**：部分搜索结果缺证据时，不再否定其他结果的可靠位置。
- **P2 · useOverlayFocus**：父子弹窗同时卸载曾将背景重新锁死。改为共享引用计数，最后一个使用者退出才恢复原状态。
- **P2 · Toast**：4.2 秒通知消失曾使焦点落到 body、弹窗 Esc 失效。只在移除当前焦点所在通知时恢复到有效弹窗或原页面控件。
