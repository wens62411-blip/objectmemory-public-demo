# 物忆：公开源码快速开始

这是供本地试用和继续开发的源码版本。默认真实模式从空数据库开始；公开仓库不携带任何人的照片、录像、密码、设备绑定或历史运行数据库。

## 安装和启动

准备 Windows 10/11、Python 3.12 和 Node.js 22。在解压或克隆后的项目根目录，先双击 `Bootstrap.bat`。首次安装需要联网下载依赖、构建前端，并生成明确标记的合成演示素材。可选视觉模型下载失败会显示警告，不代表这些模型已经可用。

安装后按用途选择一个入口：

| 入口 | 用途 |
| --- | --- |
| `Start.bat` | 本机真实模式，默认地址 `http://127.0.0.1:8018` |
| `Start-Device.bat` | 为局域网设备接入启动真实模式，然后在设备中心配置板卡 |
| `Start-No-Hardware-Demo.bat` | 独立演示模式，使用合成视频与虚拟设备 |

切换模式前关闭原服务。同一端口只运行一个服务。正常停止请在服务窗口按 `Ctrl+C`。

需要指定端口时，在 PowerShell 中运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1 -Port 8019
```

演示素材由本项目绘制生成，不含家庭摄像头实拍。演示数据库与真实数据库分开；演示中的识别和移动不能证明真实物品识别成功。

## 连接电脑摄像头或板卡

电脑摄像头：进入“摄像头”，添加电脑摄像头、测试连接，再启动实时画面。索引由电脑实际设备决定。先确认画面来自目标镜头，然后注册物品。

板卡：支持 AI Thinker ESP32-CAM 与 XIAO ESP32S3 Sense 两种固件目标。使用能传输数据的 USB 线，选择实际板型和串口。XIAO 使用自身 USB 接口；AI Thinker 板需要兼容的下载底板或 USB 串口连接。

电脑与板卡必须处在可互访的网络。热点应开启 **2.4 GHz**；允许连接设备互访。设备中心会检查网络并协助填写后端地址；填写 Wi-Fi 名称和密码后按页面提示执行配置。板卡不能用 `127.0.0.1` 访问电脑后端。密码只在自己的本机页面填写。

首次构建可能需要下载编译工具。新板安装会覆盖原程序，操作前检查页面显示的板型和串口。已经绑定并成功刷写的板优先使用恢复/重新配网入口；配网失败时先检查网络与错误提示。

依次核对：固件编译成功、串口写入成功、板卡连网、后端注册/心跳、真实截图和视频可读。任意前一阶段成功都不能替代后面阶段。自动接板只用于已明确绑定的设备，不能把未知串口当成目标板。

## 注册照片并尝试识别

照片匹配使用额外的本地模型，基础安装不包含完整的外观匹配依赖。在关闭服务后，可自行选择执行：

```powershell
.\.venv\Scripts\python.exe -B .\scripts\prepare-appearance-model.py --install-runtime
```

该命令从公开来源下载固定版本模型并核验哈希，增加本机依赖和磁盘占用；外观模型权重约 89 MB，运行时还会消耗 CPU 和内存。失败时按输出修复，不能将未就绪模型当成可用。完成后重新启动服务。

在物品管理中添加物品、上传 JPEG/PNG，确认目标框，再建立识别档案。建议使用清晰的多角度照片，并用不同于注册照片的实物视角测试。“图片保存”“档案就绪”和“摄像头识别到该物品”是不同阶段。

系统可记录有证据的“最后看到”。确认拿起、移动、放下还要求连续检测、有效运动、手物交互与离手后稳定等条件；默认放下稳定等待为 5 秒。只有黑色长方形或相似颜色不足以确认是你的手机。详细能力边界见 [已知限制](PUBLIC_KNOWN_LIMITATIONS.md)。

## 手机访问、场景与存储

通过 `Start-Device.bat` 或 `scripts/start.ps1 -Lan` 启用局域网访问后，让手机与电脑连接同一网络。在电脑页面“连接手机”获取地址/二维码与访问码。手机浏览器的语音能力取决于浏览器支持和麦克风权限。

家庭场景中的家具候选需要人工确认区域，三维视图用于展示近似方位。它不等于自动测量房间或精确三维重建。

默认 `MINIMAL` 策略保留当前状态和每件物品最近两条未固定的确认变化，保护固定事件及注册参考图。管理空间请使用存储管理页的扫描、清理预览与清理操作。不要把整个 `data/` 目录发布到 GitHub。

## 继续开发

后端位于 `apps/api`，视觉链路位于 `services/vision`，前端位于 `apps/web`，固件位于 `firmware/esp32cam`。Python 与前端依赖分别有锁定清单。常用本地验证入口：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\test.ps1 -SkipFirmware
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\test.ps1 -SkipFirmware -E2E
```

测试中的 Mock、合成视频、公开视频、物理摄像头和板卡测试要分别解读。依赖可选模型或未提供实拍样本的测试可能跳过；检查当次输出，不沿用别人的通过数字。首次浏览器测试还会安装测试浏览器。

公开仓库可以克隆、Fork 和提交 Pull Request；直接推送权限仍由仓库拥有者单独授予。提交前排除本机 `.env`、`data/`、审计截图、编译产物与任何访问凭据。
