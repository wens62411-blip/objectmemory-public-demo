# 手部动作专项（2026-09-06）

用户要求继续实现之前尚未具备的能力，本轮首先完成最明确的手部动作缺口，保留全部已有未提交改动和 REAL/DEMO/TEST 隔离。不另建 Demo、不关机、不上传家庭帧。

## 已确认缺口

现有 MediaPipe 返回手关键点；engine 只计算 hand_near 并据此写 possibly_held，没有持续的手身份、手物共同位移、释放历史。实时页默认原始预览且关键点需额外打开，因此“关键点成功”不等于“动作可用”。

## 实施模块

1. 使用已有本地 21 点实现几何手势与手运动分析，独立于物品档案：张手、握拳、指向、捏合、方向与未知，带多帧稳定门和手 ID。显示是几何解释，不是抓握事实。
2. 新增有界手物交互状态：接近、可能接触、共同携带、释放/放置候选、位置变化、遮挡未知；只绑定本帧通过身份校验的物体，不用预测框更新观察。
3. 手持记忆不能因手部短暂丢失消失；必须观察到同一只手与物体分离并重新稳定才提供放置辅助证据。相机/档案/时间连续性重置清除动作历史。
4. 实时页常驻轻量动作状态，详细同帧叠加可切换；不为显示动作重复打开摄像头或跑第二个全帧模型。
5. 运行独立序列回归、真实本地模型素材、真实后端与浏览器测试，然后替换当前服务并实测。测试输入与物理动作验收严格分开。

## 验收

手经过不移动物体不算拿起；手与物体一起移动有连续共同运动依据；静止手持和手丢失不算放下；可见分离后物体稳定才进入放置候选；无已确认物品时仍有手部动作反馈，但不生成物品事件；断流/重连不接续旧动作；所有队列有界。

不将通用 Gesture Recognizer 的张手/握拳标签当作物品拿放模型。暂不下载第二个大视觉模型。继续保留未能物理验证的明确限制，但本轮不是只补报告。
