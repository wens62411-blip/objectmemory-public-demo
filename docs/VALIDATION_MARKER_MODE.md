# 手机屏幕验证标记模式

`/companion/validation-marker` 用高对比度、静止、带白边的 ArUco 标记给真实手机提供可控身份。后端把唯一标记 ID 绑定到物品；手机页面本身没有“我已被看到”或“我已移动”的写入能力。

识别状态只来自当前 OpenCV 摄像头管线：帧编号持续增加、检测到的标记 ID 与绑定一致，并满足标记尺寸、角度、完整度和连续帧要求后，页面才显示稳定识别。手机页面保持打开不等于识别成功。

使用时应：

- 调高屏幕亮度并尽量保持常亮；若浏览器不支持 Wake Lock，请临时关闭自动锁屏；
- 避免动画、缩放手势和遮住标记边缘；
- 让完整白边出现在摄像头画面中；
- 标记太远、角度过大或部分遮挡时，按验收页提示调整；
- 不把该模式称作“完全无标签 AI 识别”。

打印备用 PNG 可以用于诊断，但本轮默认是手机全屏显示，不要求购买或打印材料。
