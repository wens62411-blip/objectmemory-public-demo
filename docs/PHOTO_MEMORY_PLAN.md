# 照片识别与最后位置主链路

基线 a8b3703；分支 codex/photo-memory-core。仅做用户指定主链路，不重新建项目、不清库、不购买硬件、不关闭电脑。

## 已定位的断点

- ItemsPage 与 reference-images API 都强制单次 6–12 张，单张起步被拒绝。
- API 对整图计算 HSV 颜色特征；没有目标框、照片档案版本或明确的构建/加载状态。颜色不能证明具体实物身份。
- 上传后运行中的 VisionEngine 缓存旧 items/reference_matcher，没有热更新。
- experimental 模型不存在时仍回退 ArUco；本轮无标签路线必须显式报模型错误，不执行标签兜底。
- 稳定首次观察实际上已有独立入库路径，不要求手/完整移动/视频；但不留观察截图，搜索与物品页的事件优先展示会掩盖观察，旧确认状态还可能在同区域或等时间状态变化时被错误保留。

## 分阶段实施与证据门

1. 单张/批量照片、原图与方向、用户确认裁剪；NanoDet 候选 + 一个 DINOv2-small ONNX 外观模型；真实特征档案、版本、热加载与同帧现场测试。先运行模型/上传/独立输入测试，再进入阶段 2。物理不同角度试验无素材时标待执行，不以注册图自匹配代替。
2. 当前观察截图与独立 last_observed / last_confirmed_placement / hypotheses，搜索按最新有效证据，不因视频失败丢失观察；增量迁移与现有 retention 保护兼容。
3. 修复现有 MediaPipe 的帧坐标/状态/叠加和交互判定；手缺失不阻断观察，静止手持不等于放下。
4. 复用区域编辑，增加低频场景建议、用户确认、SVG 示意地图与证据关联；未标定不输出米制定位。
5. 有根据才给候选区域；深度可选且默认不做，不阻塞前四阶段。

所有图像在本机处理。模型从公开官方/原发布转换库下载，固定 revision/hash/许可，推理时禁止下载。优先复用 NanoDet/OpenCV，增装固定 ONNX Runtime 不升级现有依赖。保持预览独立、有界队列和三模式隔离。测试素材隔离，用户最后只需一次集中物理试验向导。

## 已实现的收口范围

五阶段代码已落地；用法与未验证边界集中在 [PHOTO_MEMORY_GUIDE.md](PHOTO_MEMORY_GUIDE.md)。深度/三维没有先行堆叠。独立检查修正了场景帧槽解包、场景稳定性证据不足与错误状态、推测轨迹时间/来源校验；删除了被新观察门完全替代且没有读取者的 `_photo_identity_proofs` 缓存。旧测试“观察无任何图片”按本轮需求更新为一张可验证当前观察图，仍严格禁止伪造历史移动或录像。真实用户手机多视角与拿放试验待实际执行，不用测试通过数替代。
