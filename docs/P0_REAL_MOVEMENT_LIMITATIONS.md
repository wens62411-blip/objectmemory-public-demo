# P0 真实移动限制

- 当前验收使用手机屏幕 ArUco 作为受控身份标记，只验证真实视频链路、移动状态机、证据和持久化；它不证明无标签家庭物品识别已达到商用品质。
- 物理验收必须由用户实际摆放并移动手机。自动化合成帧和测试视频只用于回归，不能计入真实试验次数。
- 标记过小、反光、屏幕休眠、极端斜视、运动模糊或完全遮挡会降低识别率。完全遮挡且未在目的区域重新出现时系统不会猜测“已放下”。
- 只把本机 OpenCV 摄像头列为本轮允许的真实来源；`browser_camera`、RTSP、ONVIF、MJPEG、屏幕采集和 ESP32 均不在本轮物理通过范围内。
- 数字 OpenCV 索引只能证明帧来自本机采集接口，不能从软件上排除 OBS Virtual Camera 等系统虚拟驱动。验收操作者必须对照实时画面确认当前确实是所选物理镜头；报告应写“本机 OpenCV 来源＋现场人工确认”，不能写成硬件身份已自动证明。
- 当前没有检测到真实 ESP32-CAM，没有进行真机刷写、串口配网或真实视频验收。固件编译和虚拟设备协议不构成真机证据。
- P0 准确率只针对本次光照、相机角度、手机标记尺寸和两个人工区域；不能外推到所有家庭环境。
- 小目标压缩后若不能重新解码同一 ArUco，证据门会拒绝确认，可能增加低照度、反光或标记太小时的漏报。这是有意保持证据不足不猜测，不能把软件测试通过解读为任意拍摄条件均可用。
- SQLite、来源元数据和保留回执由本机服务管理，没有对恶意本机管理员的防篡改签名；SHA-256 用于发现错配/损坏，不是物理场景真实性的密码学保证。
